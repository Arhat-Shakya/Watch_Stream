# 🎬 WatchStream

**WatchStream** is a dark-themed movie and entertainment browsing website built using HTML and CSS. It brings anime, Bollywood, Hollywood, and series collections together in one place through a clean and modern interface.

The project focuses on frontend development, CSS layouts, interactive navigation, and user interface design.

## ✨ Features

### 🏠 Home Page
- Modern dark-themed user interface.
- Hero section featuring highlighted movie content.
- Movie thumbnails and featured content.
- Movie details including titles, release years, and ratings.
- Social media sharing interface.

### 🎭 Content Categories
- Browse popular movies.
- Dedicated Anime collection.
- Bollywood movie collection.
- Series collection.
- Category switching using HTML radio buttons and CSS selectors.
- Responsive-style movie card layouts using Flexbox and wrapping.

### 🔐 Login & Registration Page
- Separate login page.
- Sign In and Create Account interfaces.
- Email and password input fields.
- Remember Me checkbox.
- Forgot Password link.
- Full Name and Confirm Password fields for registration.
- Terms and policies agreement checkbox.
- Google and Facebook sign-in interface placeholders.
- CSS-based switching between Sign In and Create Account.

### 🎨 UI Design
- Dark-themed interface.
- Purple accent colors.
- Styled buttons, navigation, and input fields.
- Font Awesome icons.
- Hover effects and transitions.
- Dedicated footer with browsing categories, support links, and social media icons.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure and content |
| CSS3 | Styling, layouts, and interactions |
| Flexbox | Page and content alignment |
| CSS Selectors | Interactive category and login switching |
| Font Awesome 6.4.0 | Icons |

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/Watch_Stream.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code for a better development experience.
